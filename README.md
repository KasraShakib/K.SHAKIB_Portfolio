## 🇬🇧 ENGLISH | English Version

### 🌟 Overview

Welcome to my personal portfolio website! This is a modern, interactive React-based portfolio built with cutting-edge web technologies. The site showcases my skills, projects, and experience as a full-stack developer with a focus on creating beautiful and functional digital experiences.

### ✨ Features

- 🎨 **Modern & Responsive Design** - Beautiful UI that works seamlessly across all devices
- ⚡ **Fast Performance** - Built with Vite for lightning-fast development and production builds
- 🌍 **Multi-language Support** - Persian (فارسی) and English language switching
- 📧 **Contact Form** - Get in touch via integrated EmailJS
- 🎭 **Smooth Animations** - Engaging animations powered by Framer Motion
- 🔧 **Interactive 3D Elements** - Three.js & React Three Fiber for immersive 3D visuals
- 🎯 **Type-Safe** - Built with React and modern JavaScript best practices
- 📱 **Mobile Optimized** - Perfect viewing experience on smartphones, tablets, and desktops
- 🎪 **Typing Animation** - Dynamic text effects with Typewriter Effect
- 🚀 **Production Ready** - Fully optimized for deployment

### 🛠️ Technology Stack

**Frontend Framework & Build Tools:**
- ⚛️ **React 19.2.8** - Modern UI library with hooks and concurrent features
- ⚡ **Vite 8.2.0** - Next-generation frontend build tool
- 🎨 **Tailwind CSS** - Utility-first CSS framework via Vite plugin

**Animation & Interactivity:**
- 🎬 **Framer Motion 13.0.0** - Production-ready motion library
- ✍️ **Typewriter Effect 2.22.0** - Text typing animations
- 🎭 **Three.js 0.185.1** - 3D graphics library
- 🔗 **React Three Fiber 9.7.0** - React renderer for Three.js
- 📦 **React Three Drei 10.7.8** - Useful helpers for React Three Fiber

**Internationalization:**
- 🌐 **i18next 26.3.6** - Powerful i18n framework
- 🌍 **i18next-browser-languagedetector 8.2.1** - Auto language detection
- 🔤 **react-i18next 17.0.11** - React integration for i18next

**Additional Features:**
- 📧 **EmailJS 4.4.1** - Send emails directly from browser
- 🎨 **Lucide React 1.30.0** - Beautiful SVG icon library

**Development Tools:**
- 🔍 **ESLint** - Code quality and consistency checking
- 📦 **Node.js** - JavaScript runtime

### 🚀 Quick Start

#### Prerequisites
- Node.js (v16 or higher)
- npm or yarn package manager

#### Installation

```bash
# Clone the repository
git clone https://github.com/KasraShakib/K.SHAKIB_Portfolio.git

# Navigate to project directory
cd K.SHAKIB_Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:5173`

#### Build for Production

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
